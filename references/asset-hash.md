# 表情资产哈希登记与比对（防参考图被偷换 / 损坏）

> 本文件是「面部表情编码」技能的安全锁：给表情锚点图、表情参考图组登记 sha256 指纹，垫图前自动比对，防止参考图被偷偷替换、损坏或丢失。

## 为什么需要它

表情编码的命根子是**参考图**——

- **表情锚点图**（标准表情、平光、无遮挡）锁住角色的脸型与 baseline 表情；
- **表情参考图组**（同一角色在各 I 档的表情图，如悲伤 I3 / I5 / I7）锁住每个强度档的肌肉状态。

一旦这些图被：

- **误替换**（同文件名换了张别的图）
- **损坏**（传输 / 编辑中途截断）
- **删除 / 移动**（路径变了，垫图落空）

跨镜头表情就会静默漂移，而人眼极难在几十张图里发现"这张其实是另一张"。哈希指纹正好治这个：**同样的图永远同一个指纹；图被改一个像素，指纹就天差地别**。比对指纹就知道图有没有被动过，不用肉眼看。

## 工具位置

```
shiyiagi-facial-expression/scripts/asset_hash.py
```

纯 Python 3 标准库，无需安装任何包。Windows（Git Bash / PowerShell）、macOS、Linux 都能跑。

## 三步用法

### 1. 出图验收后 · 登记（init）

表情参考图组（锚点图 + 各 I 档表情图）验收锁定后，扫一遍生成指纹清单：

```bash
python scripts/asset_hash.py init <资产目录>
```

会生成 `asset-hash-manifest.json`，记录每张图的相对路径与 sha256。日后新增图片，重跑 `init` 即可更新清单。

### 2. 每镜垫图前 · 比对（check）

写每一镜、准备垫参考图之前，跑一次比对：

```bash
python scripts/asset_hash.py check <资产目录>
```

输出四类结果：

| 标记 | 含义 | 处理 |
|---|---|---|
| `OK` | 指纹一致，图没动 | 放心垫图 |
| `CHANGED` | 内容变了（被替换 / 损坏） | **停手**，找回原图或重出，否则整批漂 |
| `MISSING` | 文件不见了 | 找回原图，或确认后重跑 init |
| `ADDED` | 新文件未登记 | 跑 init 更新清单 |

`CHANGED` 或 `MISSING` 存在时，脚本退出码为 `1`（便于写进批处理 / 自动化判断）；全一致为 `0`。

### 3. 手动填表 · 单文件指纹（file）

想手动把某个图的指纹填进资产登记表（见下方模板）时：

```bash
python scripts/asset_hash.py file <图片路径>
```

直接打印该文件 sha256，复制进表的「SHA256」列。

## 怎么融入表情编码流程

| 阶段 | 动作 |
|---|---|
| 建库期（出图验收后） | 表情锚点图 + 表情参考图组验收锁定 → 跑 `init` 登记指纹 → 回填资产登记表（含 SHA256 列） |
| 每镜期（写提示词时） | 垫参考图前跑 `check` → 全 `OK` 才垫图；出现 `CHANGED/MISSING` 先解决 |
| 成片期（跨镜比对时） | 若成片疑似表情漂移，先 `check` 排除"参考图被换"这一根因，再查别的 |

> 口诀：**验收登记指纹、垫图前必 check、CHANGED/MISSING 不过不垫。**

## 表情资产登记表 · 加 SHA256 列

在原有「角色表情基线卡」之外，单独建一张表情资产登记表，末尾增加「SHA256」一列，由 `file` 或 `init` 填值：

| 类型 | 路径 | 用途 | 对应 I | SHA256 |
|---|---|---|---|---|
| 表情锚点图 | anchor_linxia.png | 锁脸 + baseline 表情 | I2（基线卡默认） | `asset_hash.py file` 取值 |
| 表情图·悲伤 | expr_grief_I3.png | 垫图·悲伤低档 | I3 | … |
| 表情图·悲伤 | expr_grief_I7.png | 垫图·悲伤高档 | I7 | … |
| 表情图·愤怒 | expr_anger_I9.png | 垫图·愤怒峰值 | I9 | … |

> 锚点图必须按「角色表情基线卡」的默认 I 值生成（通常 I2 平和），使垫图起点与渐变起点一致（见 expression-coding 第六节「基准等价」）。表情参考图组每档都要对应登记表里的 I 值，避免垫错强度档。

## 退出码（自动化用）

- `0`：check 全一致 / file 成功 / init 成功
- `1`：check 存在 CHANGED 或 MISSING（垫图前必须拦截）
- `2`：参数错误（目录 / 文件不存在、清单缺失）
