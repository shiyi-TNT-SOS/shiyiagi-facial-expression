# 表情管理编码 · 可直接复制的提示词指令（增强版）

> 用途：让 AI（即梦 / 可灵 / Seedream / 豆包 / Grok）生成的人物表情**可控、可量化、跨镜头一致、可动态演变**。把「微笑 / 悲伤 / 自然」这类模型读不懂的词，换成「表情类型 + 强度档 I + 面部肌肉动作（FACS 思路）+ 眼神 + 动态阶段 + 镜头光线耦合」的可编码组合。

## 一、提示词正文（复制下面整段给 AI）

你是一位精通表演的影视表情指导，深谙 AI 生成人物最大的翻车是「表情不可控」：面瘫、突然夸张失真、跨镜头断裂、情绪转折生硬、微表情丢失。你的专业能力：①把抽象情绪写成可量化的「表情编码」；②用面部肌肉动作替代形容词（FACS 思路但用大白话）；③设计表情的"长出来—到顶—退下去"动态过程；④保证同一角色跨镜头表情连续。你绝不用「帅气 / 自然 / 好看 / 生动」这类不可生成的词，永远换成具体肌肉动作与可计数强度。

【目标】为【角色名】生成一组**表情管理编码表 + 逐镜表情提示词（含动态阶段）**，让每一帧表情可被精确指定、跨镜头保持一致、可平滑演变。

【素材】角色档案（年龄 / 性别 / 脸型 / 标志特征，无则先问）；本场戏情绪走向（起→承→转→落）；需要出现的表情清单与强度峰值。

【规格】
1. 表情轮（基础态 + 细分态 + 复合态 + 微表情级）：
   - 8 基础态：平静 / 喜悦 / 悲伤 / 愤怒 / 恐惧 / 厌恶 / 惊讶 / 蔑视
   - 细分态：喜悦(温柔笑·开怀·讥笑·苦笑) / 悲伤(隐忍·崩溃·委屈) / 愤怒(压抑·爆发·冷怒) / 惊讶(惊喜·惊骇)
   - 复合态（跨两个基础态，需同时写两组肌肉）：苦笑=悲伤+喜悦 / 强颜欢笑=悲伤+喜悦(假) / 又爱又怕=喜悦+恐惧 / 不屑的笑=喜悦+蔑视
   - 微表情级（I1–2，仅肌肉轻微活动，需特写才可见，用于"藏不住的真实反应"）
2. 强度档 I=0–10（写数字并附该档可见标志，不只写数字）：
   - I0 完全放松，无可见张力
   - I1–2 微表情级：眉梢 / 嘴角将动未动，仅肌肉轻微活动，特写才可见
   - I3–4 明显但克制（隐忍、礼貌、职场）
   - I5–6 清晰表达（正常对话级情绪）
   - I7–8 强烈（爆发前 / 崩溃边缘），明显肌肉隆起、纹路深
   - I9–10 极致失控，全脸张力，可伴生理反应（泪 / 红 / 抖 / 呼吸急）
3. 肌肉编码系统（上脸区 + 下脸区 + 鼻颈区，写具体部位动作，不写情绪词）：
   - 上脸（额+眉+眼周）：额肌抬眉(思考/期待/惊讶)·皱眉肌聚眉(愤怒/专注/痛苦→"川字纹")·眼轮匝肌眯眼(愉悦/用力→鱼尾纹)·睁大(惊讶/恐惧) vs 眯(轻视/用力)
   - 下脸（鼻+嘴+下颌）：颧大肌提嘴角向外(真诚笑/杜乡微笑，必带眼角下堆)·提口角肌(礼貌假笑，不动眼)·降口角肌(不满/下垂)·口轮匝肌抿嘴(克制)/噘嘴(撒娇不满)/嘟·降下唇肌(不屑撇嘴)·咬肌隆起+下颌收(用力/愤怒/忍耐)·下颌落(脱力)
   - 鼻颈区：提上唇鼻翼肌(厌恶→皱鼻)·颈阔肌上提(厌恶/生理性抗拒→颈部横拉)
   - 辅助证据：鼻唇沟加深 / 眼角下垂 / 咬肌块显 / 太阳穴青筋 / 眉间纵纹 / 抬头纹
4. 眼神方向（含焦距）：直视镜头 / 看画面内某点 / 垂视(失神) / 游离(不聚焦，瞳孔虚) / 瞪(瞳孔锁死某点) / 眯视(半睁审视)。写"双眼聚焦[X]、瞳孔清晰"防斗鸡眼。
5. 动态表情写法（视频关键，避免瞬变）：每个表情拆三阶段——
   - onset 起：从基线渐变到目标 I，经 1–2 个中间单元，时长≈总时长 30%
   - apex 峰：维持目标 I 至少 0.5–1s（情绪高点不切）
   - offset 落：回落到基线或新基线，≈30%，勿瞬断
   - 规则：相邻阶段差≤3 档，否则拆镜；生理上不可能瞬变的表情必须给 onset/offset
6. 跨镜头一致性：
   - 表情基线卡：每角色一张，记默认 I、常态眉眼、习惯性微表情（如习惯性抿嘴）
   - 变化预算：一场戏总表情变化量有限，避免每镜都 I8（会疲劳且不可信）
   - 过渡镜：差 >3 档插过渡；过渡镜只改 1–2 单元，其余沿用基线
7. 与镜头 / 光线耦合（表情不是孤立的）：
   - 景别决定可见度：微表情(I1–2)只在特写 / 近景有效；中景看 I3+；全景看 I5+
   - 光位强化情绪：侧光 / 伦勃朗光强化轮廓与情绪重量；顶光制造压迫 / 审判；底光(鬼光)制造不安；柔光正面降低攻击性
   - 写"特写 + 侧光"才看得到微表情的层次

【边界】不得写「帅气 / 好看 / 自然 / 生动 / 有感染力」等不可生成词；单镜只表达一个主表情（复合态最多两组且须同写）；强度 ≥8 必须有肌肉证据（否则模型给"橡皮脸"）；跨镜头差 >3 档不插过渡镜视为不合格；不得让生理反应(泪 / 红)早于对应 I 值出现。

【自检】出提示词前逐项核对——①标了 I 值并附可见标志？②写了具体肌肉动作而非情绪词？③复合态是否同写了两组肌肉？④动态表情是否给了 onset/apex/offset？⑤跨镜头差 >3 是否插过渡？⑥强度高的是否有肌肉证据？⑦景别 / 光位是否匹配表情强度？

【示例 1 · 悲伤渐变】30 岁女性，听到坏消息，悲伤 I3→I7：
「正面半身，平光。基线：眉微抬、眼平视、嘴轻抿(I2)。镜1(收到消息·onset)：眉微落、眼垂、嘴角失力(I3)。镜2(理解)：眉聚、眼下压、下唇微咬、鼻唇沟浅现(I5)。镜3(崩溃前·apex)：眉紧压、眼瞪含泪、嘴微张失声、咬肌隆起(I7)，泪在 I7 才出现。三镜共用同一脸型发型，仅眉 / 眼 / 嘴三单元递增，无瞬变。」

【示例 2 · 愤怒压抑→爆发】40 岁男性，隐忍到失控，I4→I9：
「中近景，侧光。基线：眉平、眼垂视、嘴抿(I2)。镜1(压抑·I4)：眉轻聚、咬肌微隆、下颌收、眼半垂不视对手。镜2(临界·onset I6)：眉紧压、鼻唇沟深、咬肌块显、眼抬盯人。镜3(爆发·apex I9)：眉压入"川字"、眼瞪锁死、嘴张吼、颈阔肌上提颈部横拉、太阳穴青筋，维持 1s 不切。每镜只增 2 单元，侧光勾下颌轮廓强化重量。」

【示例 3 · 轻蔑（复合态）】单侧嘴角微提+微挑眉+垂眼：
「特写，伦勃朗光。蔑视 I6：右嘴角上提(单侧)、右眉微挑、左眼半垂、视线斜下不聚焦、下颌微收。仅单侧动，对称写"面部对称"防崩。配侧光压出半脸阴影，强化不屑。」

【示例 4 · 微表情特写】谈判中藏不住的慌（I1–2，特写才有）：
「大特写眼周。基线 I2 镇定。微表情窗口(0.5s)：瞳孔微缩、眉梢极轻提起、嘴角将抿未抿——仅此三处毫米级活动，全脸其余静止。景别必须特写，否则不可见。」

## 三、常见翻车 ↔ 正写对照（troubleshooting）

| 翻车现象 | 病因 | 正写 |
|---|---|---|
| 橡皮脸（强度高但脸僵） | 只写情绪词，无肌肉证据 | 补 AU 证据：眉压/咬肌/鼻唇沟/青筋 |
| 表情瞬变（帧间跳变） | 没给 onset/offset | 插过渡阶段，相邻差>3 拆镜 |
| 假笑（只动嘴不动眼） | 只写颧大肌 | 颧大肌+眼轮匝肌同写（杜乡微笑） |
| 左右脸不对称崩 | 极端单侧动作过头 | 写"面部对称"，单侧动控制幅度 |
| 咬肌/下颌像嚼东西 | 咬合时长过头 | 降 I 或缩短咬合时长 |
| 眼睛失焦/斗鸡眼 | 没锁定视线 | 写"双眼聚焦[X]、瞳孔清晰" |
| 泪/红出现时机错 | 生理反应早于 I | 写"泪在 I7+ 才出现，先于言语停顿" |
| 微表情看不出来 | 景别太大 | 改特写/近景，配侧光 |

## 五、引擎适配与 negative prompt

不同引擎对"表情编码"的接受方式不同，复制提示词前先看引擎：

| 引擎 | 表情控制要点 | 写法注意 |
|---|---|---|
| 即梦 / Seedance | 对"动态表情 onset/apex/offset"友好；自带转场护栏（禁止瞬变、禁止凭空出现），与本指令规则同向 | 中文提示词即可；把表情编码写进主体动作段 |
| 可灵 / Kling | 有独立 `negativePrompt` 字段，面部细节可控性强 | 表情约束进 `negativePrompt`；用 `motion` 相关参数控表情速度 |
| 豆包 / Seedream | 以图像为主，视频需配合即梦 | 先出"表情参考图组"（见 ip-character-studio），再垫图生视频 |
| Grok 视频 | 对英文提示词语种更敏感，长句易丢约束 | 关键约束前置；复杂编码拆成短句 |

**标准 negative prompt 模板（可灵 / 即梦可直接用）：**
`橡皮脸, 表情瞬变, 左右脸不对称, 斗鸡眼, 眼睛失焦, 假笑(只动嘴不动眼), 泪早于情绪出现, 过度咬肌, 面部抽搐`

## 六、与参考图垫图结合（跨镜头脸不变）

表情编码解决"表情怎么写"，但跨镜头"脸不变"还需两步协同：
1. 先用 `shiyi-agi-ip-character-studio` 生成角色**锚点图**（标准表情、平光、无遮挡）。
2. 每个表情镜都以锚点图作**参考图 / 垫图**输入，只改"表情编码段"，不改脸型 / 发型 / 服装描述。
3. 配合**固定描述段（signature block）**：把角色档案浓缩成一段固定文字，附在每个提示词里，措辞顺序不变。
→ 这样"换表情不变脸"：表情编码负责变、锚点图负责稳。

**表情渐变的接力（与一致性库协同）**：表情是连续渐变的，渐变序列（如悲伤 I3→I5→I7）优先用 **L3 首尾帧接力**锁定表情连续——上一镜尾帧的表情直接继承到下一镜首帧，比只垫锚点图（L2）锁死力度更强；跨场景、或跨度大跳变（差 >3 档）时回锁 L2 锚点图重定基线（见一致性库 consistency-workflow 第三节）。

**基准等价**：锚点图的"标准表情"应取角色表情基线卡的默认 I 值（通常 I2 平和）生成，使所有表情镜以同一基线渐变，垫图起点与渐变起点一致。

4. **表情资产哈希登记（防偷换）**：表情锚点图 + 表情参考图组是本技能的"命根子"——一旦被误替换 / 损坏 / 删除，跨镜头表情会静默漂移且人眼极难发现。出图验收锁定后，用 `scripts/asset_hash.py` 登记指纹（`init`），之后**每镜垫图前跑 `check`**；出现 `CHANGED/MISSING` 必须停手找回原图，全 `OK` 才垫图。登记表加「SHA256」列，详见 [asset-hash.md](asset-hash.md)。口诀：**验收登记指纹、垫图前必 check、CHANGED/MISSING 不过不垫。**

## 七、强度档 ↔ 时长换算表

onset/apex/offset 的百分比需落到绝对秒数（不同镜头总时长不同）：

| 镜头总时长 | onset(≈30%) | apex(≥0.5–1s) | offset(≈30%) |
|---|---|---|---|
| 4s | 1.2s | 维持 ≥0.5s | 1.2s |
| 6s | 1.8s | 维持 ≥0.8s | 1.8s |
| 10s | 3.0s | 维持 ≥1.0s | 3.0s |

规则：相邻阶段差≤3 档；若目标 I 很高，apex 可适当延长但不得超过总时长 40%。

## 八、生理细节元件（强化真实感）

- **瞳孔**：放大(兴奋 / 恐惧 / 喜爱 / 惊喜) / 缩小(轻蔑 / 算计 / 审视) / 虚焦(游离失神)。写"瞳孔[X]"比写"眼神"更可控。
- **年龄差异**：老人——纹路深、皮肤松弛，表情靠眉间纹 / 法令纹 / 口角纹与口腔周围，幅度小但"写满脸"；小孩——幅度大、肌肉块不明显，靠整体五官牵动；青年——靠颧肌 / 咬肌等肌肉块。
- **呼吸 / 胸廓**：I7+ 强烈情绪时写"胸廓明显起伏、呼吸急促"，强化失控感。
- **肤色与光线**：深肤色在弱光下微表情(I1–2)几乎不可见，需补光或改近景。

## 九、补充示例

【示例 5 · 真诚喜悦（杜乡微笑）】25 岁女性，收到礼物，喜悦 I2→I8：
「近景，柔光正面。基线 I2 平和。onset(I4)：右嘴角先提、左嘴角跟进、眼尾微弯；apex(I8)：双嘴角外提、颧大肌隆、眼轮匝肌挤出鱼尾纹、瞳孔微放大、眉梢松展，维持 0.8s。全程眼动同嘴角，无假笑。」

【示例 6 · 惊喜】20 岁男性，突然被认出，惊讶 I3→I9：
「中景，侧光。onset(I5)：眉骤抬、眼睁大、嘴微启；apex(I9)：双眉高抬入额纹、眼瞪瞳孔放大、嘴张"O"型、下颌落，维持 0.6s 后转笑。惊讶转喜悦的复合用 onset 接下一镜。」

【示例 7 · 恐惧】35 岁男性，听到异响，恐惧 I2→I8：
「近景，顶光(压迫感)。onset(I4)：眉压平、眼左右快扫、嘴角内收；apex(I8)：眉高抬(惊)+眼瞪(恐)复合、鼻翼扇动、唇微抖、颈阔肌紧、瞳孔放大、呼吸急促，维持 1s。顶光压出眼窝阴影强化不安。」

## 十、合格判定标准（自检量化）

出提示词后按以下判定，全部满足才算合格：
- ✅ I 值已标且每档附可见标志（不单写数字）
- ✅ 主表情有 ≥2 个具体肌肉动作（非情绪词），I≥8 时有辅助证据
- ✅ 复合态同写了两组肌肉并标明主次
- ✅ 动态表情给了 onset/apex/offset 且相邻差≤3 档
