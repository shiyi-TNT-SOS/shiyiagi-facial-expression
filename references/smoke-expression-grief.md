# 行为冒烟示例（等级 2）· 悲伤渐变编码

> 本文件是 `shiyiagi-facial-expression` 的可执行测试：用「林夏听到坏消息，悲伤 I3→I7 跨 3 镜」，跑通「表情编码表 → 逐镜提示词（含 onset/apex/offset）→ 合格判定」，证明本 skill 能落地而非空话。

## 0. 测试场景

角色：林夏（28 岁，圆脸大眼，左额挑染，藏青制服）。情绪：悲伤从隐忍到崩溃边缘。引擎：即梦 / Seedance。跨 3 镜，无瞬变。

## 1. 表情编码表

- 表情轮：悲伤（细分态：隐忍 I3 → 崩溃边缘 I7）
- 强度档：I3（明显但克制）→ I5（清晰表达）→ I7（强烈，将崩未崩，带生理反应）
- 肌肉（上脸）：皱眉肌聚眉（痛苦）→ 眉紧压；眼轮匝肌眼下压
- 肌肉（下脸）：降口角肌下垂 → 下唇微咬 → 嘴微张失声
- 鼻颈：鼻唇沟浅现 → 颈阔肌微紧
- 眼神：平视 → 眼垂 → 眼瞪含泪（瞳孔虚）
- 动态：onset(镜1, ≈30%) → apex(镜3, ≥0.5s) → offset(未到)

## 2. 逐镜提示词（七段 + 表情编码）

**镜 1（onset I3）**
> [林夏收到消息，眉微落、眼垂、嘴角失力] + [正面半身·平视] + [固定] + [平光] + [自然调] + [生成 4s] + [环境静]
> 表情编码：悲伤 I3，皱眉肌轻聚、降口角肌微落，眼神下垂，无生理反应。

**镜 2（I5）**
> [理解内容，眉聚、眼下压、下唇微咬、鼻唇沟浅现] + [近景·平视] + [微推] + [侧光勾脸] + [冷调] + [生成 5s] + [呼吸声]
> 表情编码：悲伤 I5，眉紧压、眼轮匝肌眼下压、下唇咬，鼻唇沟现，眼神半垂。

**镜 3（apex I7，含泪）**
> [崩溃前，眉压入川字、眼瞪含泪、嘴微张失声、咬肌隆起] + [中近景·微仰] + [固定] + [顶光压眼窝] + [低饱和] + [生成 5s·apex 停留 ≥0.8s] + [静默后破音]
> 表情编码：悲伤 I7，眉压、眼瞪含泪（泪在 I7 才现）、嘴张失声、咬肌隆，泪先于言语。

## 3. 合格判定（8 项勾选）

- [x] I 值已标且每档附可见标志
- [x] 主表情 ≥2 具体肌肉动作；I7 有辅助证据（咬肌/鼻唇沟/泪）
- [x] 非复合态，无需两组肌肉
- [x] onset/apex 给定，相邻差 ≤3 档（3→5→7，每跳 2）
- [x] 跨镜差 >3 已插过渡（镜1→3 经镜2）
- [x] 景别匹配：I5+ 近景可见，微表情未用特写
- [x] 已配 negative（橡皮脸/瞬变/不对称/斗鸡眼/泪早于情绪）
- [x] 与锚点图垫图协同，固定描述段一致
